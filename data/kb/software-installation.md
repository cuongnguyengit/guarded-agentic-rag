# Installing Software

## Approved catalogue
Install software only from the Lumen Software Center. Applications in the catalogue are already approved and patched automatically.

## New software
To request software that is not in the catalogue, open a "Software request" ticket. Security reviews new software within 5 business days; browser extensions are reviewed as software too.

## Developer tools
Package managers such as pip and npm may be used on developer machines, but packages must come from the internal mirror, which scans for known malicious packages.
