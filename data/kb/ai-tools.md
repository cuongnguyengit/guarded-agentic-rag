# Using AI Assistants

## Approved assistants
Employees may use the internal Lumen Assistant for work. External AI chatbots may be used only with Public data.

## Prohibited input
Never paste Confidential or Restricted data, credentials, customer personal data or proprietary source code into an external AI tool.

## Reviewing AI output
You are responsible for reviewing AI-generated content before using it. Do not run AI-suggested commands on production systems without peer review.
